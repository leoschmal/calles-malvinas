# Calles Malvinas

Propuesta vecinal para la nomenclatura de calles del barrio Altos del 
Paracao (Paraná, Entre Ríos), en homenaje a las Islas Malvinas.

## Sobre el proyecto

Este proyecto fue desarrollado en el marco de la convocatoria municipal 
para propuestas de nombres de calles del barrio, presentando una 
alternativa a la actual numeración con nombres que aporten historia, 
identidad y sentido a la comunidad.
